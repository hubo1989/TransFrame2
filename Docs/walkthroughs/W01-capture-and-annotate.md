# W01 Capture and annotate (CAP-*, INP-*, ANN-*)

**Preconditions:** Screen Recording granted; two displays connected if available; TransFrame 2 running from the menu bar.

| # | Step | Expected | Pass |
|---|---|---|---|
| 1 | Play a video, press ⌘⇧4 | Every display freezes within 150 ms; the video stops moving under the overlay | ☐ |
| 2 | Hover a window | Window outline and title label; Tab cycles overlapping candidates; Space toggles free selection | ☐ |
| 3 | Drag a region across both displays | One selection spans the gap; size label shows pixels of the denser display | ☐ |
| 4 | Arrow / Shift-arrow / Option-arrow | Moves 1 pt / 10 pt / resizes; never leaves the displays | ☐ |
| 5 | Press R, draw; press 2, draw with ⌘ | Rectangle; circle constrained by ⌘ | ☐ |
| 6 | Add text (T button), number labels, redaction; ⌘Z / ⇧⌘Z | Each gesture is one undo step | ☐ |
| 7 | Press Enter | Image on clipboard matches the overlay pixel for pixel (paste into Preview) | ☐ |
| 8 | ⌘⇧3 | Display under the pointer opens in the editor and is on the clipboard | ☐ |
| 9 | Esc during selection; right click | Capture cancels, nothing copied | ☐ |
