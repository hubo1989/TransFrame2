# W03 Text translation (TXT-*)

**Preconditions:** Accessibility granted; TextEdit and a browser open.

| # | Step | Expected | Pass |
|---|---|---|---|
| 1 | Select text in TextEdit, ⌘⇧T | HUD, then a popup near the pointer; ⌘C copies; Esc closes | ☐ |
| 2 | Select text, ⌘⇧Y | Selection replaced by the translation; clipboard unchanged | ☐ |
| 3 | ⌘⇧Y, then switch app before it finishes | Not inserted into the wrong app; translation copied with a notice | ☐ |
| 4 | Press ⌘⇧T twice quickly | Only one run | ☐ |
| 5 | Arabic text | Popup lays out right-to-left | ☐ |
