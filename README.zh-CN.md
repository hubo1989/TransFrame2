# TransFrame 2

**在 macOS 上一键截图、标注、识别与翻译。**

TransFrame 2 是一款菜单栏应用：按下快捷键的瞬间冻结屏幕，直接在冻结画面上框选、标注、打码，并就地识别或翻译其中的文字。
它是 TransFrame 1.x 的全新重写版，以独立应用（`com.transframe.v2`）安装，可与 1.x 同时运行，不导入 1.x 的设置、密钥和历史。

[English](README.md) · [更新日志](CHANGELOG.md) · [参与贡献](CONTRIBUTING.md) · [安全](SECURITY.md)

> **状态：0.0.1 预览版。** 已按 [`SPEC.md`](SPEC.md) 的 1.x 对等清单实现全部功能，但仍然年轻，遇到问题请提 Issue。

## 系统要求

- macOS 15 Sequoia 及以上，Apple 芯片与 Intel 通用。
- macOS 26 额外提供 Apple 翻译、结构化文档识别和 Apple 基础模型；其余功能在 15 上都可用。
- 权限：**屏幕录制**（截图）和**辅助功能**（划词翻译与全局快捷键），首次启动的引导会逐步带你开启。

## 安装

1. 从 [Releases](https://github.com/hubo1989/TransFrame2/releases) 下载 `TransFrame-2-<版本号>.dmg`。
2. 打开后把 **TransFrame 2** 拖进「应用程序」。
3. 从「应用程序」启动，菜单栏出现图标，引导窗口会请求上面两项权限。

安装包使用 Developer ID 签名并经过 Apple 公证。更新通过 Sparkle 推送（关于窗口 › 检查更新…）。

## 功能

### 截图
- **区域截图**（⌘⇧4）、**指针所在显示器全屏**（⌘⇧3）、**截图后翻译**（⌘⇧T）和**滚动长截图**。按下快捷键时所有显示器同时冻结，视频和菜单都会停住。
- **自动识别窗口**：指针下的窗口自动高亮，单击选中，双击保存。按 Tab 切换重叠窗口，按空格切换自由框选。选区外单击或按 Esc 退出截图。
  可在「设置 › 通用 › 截图」中关闭。
- 方向键微移选区（Shift 一次 10 点，Option 调整大小），`C` 复制指针处像素的 HEX 色值，`回车` 或 ⌘C 复制并关闭，
  ⌘S 保存，`P` 钉图，`T` 翻译，`Esc` 逐级退出。

### 标注
- 11 种工具：矩形、椭圆、直线、箭头、手绘、高亮、马赛克、文字、编号、隐私遮挡、气泡，既可在冻结画面上直接画，也可在编辑器里画。
  字母键选工具，数字 1–9 按工具栏顺序选，按住 ⌘ 画正方形、正圆和 45° 线。
- **每个按钮都有悬停提示**：名称、快捷键和一句用法，在全屏截图画面上同样可见。
- **样式条**跟随当前工具或选中的标注：色板、屏幕取色、系统颜色、线宽、字号、马赛克强度、填充与填充色。刚画好的标注保持选中，
  可以立刻调整；改样式只改被调整的那一项，拖动一次滑块只记一步撤销。
- 移动、缩放、调整端点和气泡指向，方向键微移，⌫ 删除，50 步撤销。
- **美化**：圆角加柔和阴影，外围保留透明留白。
- **智能马赛克**：在本机扫描图片，逐个高亮检出的隐私区域并一步打码（可撤销），然后提示「已完成打码，共 N 处」或「未检测到隐私信息」。

### 识别与翻译
- 识别引擎：Apple Vision、PaddleOCR（本地或云端），或视觉大模型（OpenAI 兼容、Claude、Gemini、本地模型）。
- 翻译引擎：Apple 翻译、MTranServer、OpenAI 兼容（可配置多个实例）、Claude、Gemini、Google、DeepL、百度；
  最多 5 个引擎组成兜底链，或 2–4 个引擎并排对比、切换不重译。
- 结果显示在选区旁的抽屉里，或直接画在图上（原文下方或替换原文，默认自动选择）。
- 已经是目标语言的行保持原样：不发给任何引擎，图上也不会重复画一遍"译文"。

### 任意应用中的文字
- ⌘⇧Y 翻译任意应用中选中的文字；⌘⇧I 翻译后写回原处，写入前先核对目标，失败时改用粘贴并恢复剪贴板。

### 编辑器、钉图与历史
- 非破坏性裁剪，导出 PNG / JPEG / HEIC，上传到 PicGo、阿里云 OSS、腾讯云 COS 或七牛 Kodo。
- 钉图悬浮在其他窗口之上，滚轮缩放（25–400 %），⌥+滚轮调透明度，支持鼠标穿透和置顶。
- 翻译历史支持搜索、收藏、导出 JSON / CSV / Markdown 和可选的本机语义搜索；另有独立的取色历史（⌃⌘C 在任意位置取色）。

### AI（全部可选）
- 保留结构的识别（表格、公式、代码）、智能操作（表格复制为 Markdown/CSV、打开链接、添加日程）、
  术语表「纠正并记住」、语气改写、按内容自动命名文件；在支持的系统上使用本机基础模型。

### 隐私
- 任何内容发往云端引擎之前，都会先在本机检测并遮蔽敏感信息（密钥、银行卡号、证件号、密码等）。你自己打的码始终会被烧录进图片。
  没有遥测，不需要账号。

### 界面
- 10 种界面语言（English、简体中文、Deutsch、Español、Français、Italiano、日本語、한국어、Português、Русский），即时切换。
  支持浅色/深色外观，macOS 26 上使用 Liquid Glass，全程提供 VoiceOver 标签。

## 默认快捷键

| 操作 | 快捷键 |
|---|---|
| 区域截图 | ⌘⇧4 |
| 全屏截图（指针所在显示器） | ⌘⇧3 |
| 截图后翻译 | ⌘⇧T |
| 翻译选中文字 | ⌘⇧Y |
| 翻译并插入 | ⌘⇧I |
| 屏幕取色 | ⌃⌘C |

都可以在「设置 › 快捷键」中修改。如果与 TransFrame 1.x 或系统快捷键冲突，应用会提示并引导你修改。

| 截图或编辑时 | |
|---|---|
| 复制并关闭 | `回车`、⌘C |
| 保存 | ⌘S |
| 钉图 | `P` |
| 翻译（截图中）/ 裁剪（编辑器中） | `T` / `C` |
| 选择工具 | `R O L A D H M T N X B`、`1`–`9` |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 逐级退出（文字 → 选中 → 工具 → 关闭） | `Esc` |

## 从源码构建

需要 Xcode 26.2 及以上和 Homebrew。

```sh
brew install xcodegen swiftlint
git clone git@github.com:hubo1989/TransFrame2.git && cd TransFrame2
xcodegen generate                      # 生成 TransFrame2.xcodeproj（已提交；修改 project.yml 后需重新生成）
Scripts/build.sh Debug                 # → build/Products/Debug/TransFrame 2.app
open "build/Products/Debug/TransFrame 2.app"
```

Debug 版的 bundle ID 是 `com.transframe.v2.dev`，不会影响已安装的正式版。想让系统隐私权限在重新构建后保留，
用你的 Apple Development 身份签名 Debug 版：`Scripts/dev-sign.sh`。

测试与质量门禁见 [CONTRIBUTING.md](CONTRIBUTING.md)。
